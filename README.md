# Cosmetics & Beauty Products — Global Market Analysis 2024

## Overview
End-to-end data analysis project on a global cosmetics and beauty products dataset, demonstrating a complete BI pipeline: data exploration, SQL analysis, and interactive dashboard visualization.

## Business Questions
1. Is there a relationship between price and rating?
2. Which categories have the best price/quality ratio?
3. How does price vary by skin type or gender target?
4. What percentage of products are cruelty-free by brand and country?
5. Which countries have the most presence and how do they compare?

## Tech Stack
- **Python** (pandas) — data exploration and cleaning
- **SQLite** — relational database and SQL queries
- **Tableau Public** — interactive dashboard
- **VS Code** — development environment
- **Git/GitHub** — version control

## Dataset
Source: Kaggle — Top Beauty & Cosmetics Products Worldwide 2024
Size: 15,000 products | 14 columns
Note: Synthetic dataset used for portfolio purposes.

## Key Findings
- No significant relationship between price and rating
- Contour and BB Cream show best price/quality ratio
- Pricing is uniform across skin types and gender targets
- France leads in cruelty-free products (51.58%)
- Italy and USA have highest product presence
